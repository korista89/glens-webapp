# 🎓 Glens 웹앱

특수교육 학생을 위한 행동지원 웹 애플리케이션

## 📌 주요 기능
- 행동 데이터 수집 및 분석
- PBS(Positive Behavioral Support) 모니터링
- 개별화 교육 프로그램 관리

## 🛠 기술 스택
- Python 3.x
- [프레임워크 이름 - Flask/Django/Streamlit 등]

## 📦 설치 방법

### 1. 리포지토리 클론
```bash
git clone https://github.com/korista89/glens-webapp.git
cd glens-webapp
```

### 2. 가상환경 생성 및 활성화
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 또는
venv\Scripts\activate     # Windows
```

### 3. 의존성 설치
```bash
pip install -r requirements.txt
```

### 4. 실행
```bash
python app.py  # 메인 파일명에 맞게 수정
```
